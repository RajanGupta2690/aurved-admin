# 🚀 AURVED Admin - Quick Start Guide

## ⚡ Super Fast Setup

### Step 1: Navigate to Project
```bash
cd /Users/appsmartz/IdeaProjects/aurved-admin
```

### Step 2: Start Development Server
```bash
npm run dev
```

### Step 3: Open Browser
```
http://localhost:5173
```

**That's it! Application is running! 🎉**

## 🔗 Push to GitHub

### Create new repository on GitHub:
```
Name: aurved-admin
Description: AURVED School Admin Platform
```

### Push code:
```bash
cd /Users/appsmartz/IdeaProjects/aurved-admin

# Add remote
git remote add origin https://github.com/YOUR_USERNAME/aurved-admin.git

# Push
git push -u origin main
```

---

## 🌐 Deploy to Vercel (Fastest)

```bash
# Install Vercel CLI
npm install -g vercel

# Login
vercel login

# Deploy
vercel --prod
```

**Live in 2 minutes! ✨**
